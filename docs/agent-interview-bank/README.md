# Agent 面试题库（基于本平台）

这是一套面向 `Agent / 多 Agent / Agent 平台工程化` 的中文面试题库 v1。

它不是只给出问题清单，而是尽量把每道题都做成可直接用于面试的材料：

- 按专题拆分，方便你后续继续扩题
- 每个专题都按 `初级 -> 中级 -> 高级` 递进
- 每道题都同时给出：
  - 理论参考答案
  - 结合本项目的案例答案
  - 继续追问方向
  - 面试官判分点

这套题库默认以你当前这个项目 `Agent Workflow Platform v0.2` 作为项目案例底座。

## 题库定位

适合以下几类使用场景：

- 你自己准备 Agent 方向面试时做“自问自答”
- 面试别人时，快速按专题和难度抽题
- 做团队内部分享，把抽象理论和真实项目结合起来
- 训练候选人从“会讲概念”升级到“能讲工程落地”

## 使用建议

- 校招 / 初中级工程师：
  - 优先使用 `01 ~ 05`
  - 重点看候选人是否讲清楚基本概念、工具链路、Workflow 思维
- 中高级 Agent 应用工程师：
  - 优先使用 `02 ~ 08`
  - 重点看候选人是否能把 Prompt、Memory、Tool、Evaluation、Meta-Agent 串起来
- 平台 / 架构方向：
  - 优先使用 `06 ~ 09`
  - 重点看候选人是否能从单功能 Agent 讲到平台化、可靠性、安全边界和演进路线

## 难度定义

- `初级`：能解释概念、说清基本链路
- `中级`：能比较方案、说明边界和权衡
- `高级`：能从工程、平台、可靠性、组织协作角度给出系统性答案

## 建议反复引用的平台视角

这套题库里的“项目案例答案”，建议你尽量站在下面这些视角去讲，而不是陷进实现细节：

- 产品视角：
  - 这是一个可视化 Agent 工作流平台，不是单一聊天应用
  - 平台同时覆盖编排、运行、调试、评测、开发台、资产管理和 Meta-Agent
- 运行视角：
  - 它不是一次性调用模型，而是有完整运行链路、状态、事件、工具、重跑和恢复
- 平台视角：
  - 它已经开始把 Prompt、Tool、Memory、Evaluation 做成平台能力，而不是散落在单点功能里
- 工程视角：
  - 它的优点是闭环完整、可观测性强、功能覆盖广
  - 它的边界是当前更适合单工作区 / 本地平台，而不是成熟的企业级多租户平台

如果你想先熟悉项目全貌，再回来看题库，建议先把项目自己的架构说明和功能说明过一遍，再开始练这套题。

## 这套题库的答题目标

一份好的 Agent 面试答案，通常至少要回答四层问题：

1. 这个概念是什么
2. 为什么要这样设计
3. 有哪些替代方案和边界
4. 在真实项目里如何落地、如何验证、如何暴露问题

如果候选人只能讲第 1 层，通常说明停留在“概念知道”。
如果能讲到第 3、4 层，才更像真的做过 Agent 项目。

建议你以后新增题目时，统一保留这几个结构：

- 题目
- 考察点
- 参考答案：理论
- 参考答案：项目案例
- 继续追问
- 面试官看点

这样题库会越来越像一个可复用的内部知识系统，而不是一次性文档。
